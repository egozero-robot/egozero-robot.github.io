EgoZero:
A Unified Egocentric Teleoperation Framework

Paper arXiv Video Code

We present, EgoZero, a minimal system that trains zero-shot robot policies on in-the-wild egocentric human data without any robot data

Abstract

We present EgoZero, a unified egocentric teleoperation framework that enables robotic imitation and control from both first-person and third-person perspectives. While most existing robot learning approaches rely on third-person demonstrations, humans predominantly learn from first-person experiences. EgoZero bridges this gap by learning a shared action representation from time-synchronized first- and third-person videos. This representation enables the robot to learn from large-scale third-person video data and execute manipulation through egocentric teleoperation using lightweight wearable devices such as smartphones and VR headsets. We demonstrate EgoZero across a suite of real-world manipulation tasks, showing that it achieves robust performance in contact-rich and long-horizon scenarios. Our results highlight the effectiveness of integrating egocentric perspectives into robot learning and control.

Overview

EgoZero trains policies in a unified state-action space defined as egocentric 3D points. Unlike previous methods which leverage multi-camera calibration and depth sensors, EgoZero localizes object points via triangulation over the camera trajectory, and computes action points via Aria MPS hand pose and a hand estimation model. These points supervise a closed-loop Transformer policy, which is rolled out on unprojected points from an iPhone during inference.
